CredSeek API

Bearer JWT. User biasa butuh langganan aktif (`active`/`trial`). Admin & Dev bypass.

Buka di Settings

Auth

POST /api/auth/login

{
  "email": "user@company.com",
  "password": "secret123",
  "rememberMe": true
}

Response: token + user.subscription.

GET /api/auth/me — Authorization: Bearer <token>

Subscription

GET /api/subscription/plans — daftar paket (publik)

GET /api/subscription/me — status langganan

POST /api/subscription/checkout

{ "planId": "starter" }

Response: payment.qrString, payment.id, payment.providerPaymentId.

GET /api/subscription/payments/:id — cek & sync status

GET /api/subscription/payments — riwayat payment

Tanpa paket aktif → 402 SUBSCRIPTION_REQUIRED.

Search

GET /api/search?q=example.com&filter=domain&page=1&limit=50

  • Guest: hasil terbatas & tersensor
  • Member aktif/trial: hasil penuh
  • Member tanpa paket: 402
curl -H "Authorization: Bearer $TOKEN" \
  "https://YOUR_HOST/api/search?q=gmail.com&filter=domain&limit=20"

Admin (trial & aktivasi)

UI: Settings → Accounts (Trial days / Set trial).

POST /api/users — body boleh trialDays (role user)

POST /api/admin/trial-users

{
  "name": "Client Trial",
  "email": "client@example.com",
  "password": "temporary",
  "planId": "starter",
  "days": 7
}

POST /api/admin/users/:id/subscription

{
  "action": "trial",
  "planId": "starter",
  "days": 7
}

Error codes

401 Unauthorized
402 SUBSCRIPTION_REQUIRED
403 Forbidden (role)
502 Payment provider error
